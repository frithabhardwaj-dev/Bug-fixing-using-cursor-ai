# Lecture 8 - Fixing a Buggy Python Script Using AI

This project demonstrates the RED -> FIX -> GREEN debugging cycle.

`student_utils.py` contains the corrected implementation. `test_student_utils.py` contains the nine expected-behaviour tests from the lecture guide.

Run the final suite with `python test_student_utils.py`. The final result is nine passing tests. The bug causes and fixes are recorded in `bug_notes.md`.
